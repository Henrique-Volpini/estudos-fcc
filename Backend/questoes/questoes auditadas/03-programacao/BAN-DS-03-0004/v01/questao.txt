ENUNCIADO
Considere o programa em C11:

#include <stdio.h>

int main(void) {
    int v[] = {3, 5, 7, 9};
    int *p = v + 1;
    *(p + 1) = *p + v[0];
    printf("%d %d", v[2], *(p - 1));
    return 0;
}

A sequência exibida por printf é

A) 7 3
B) 8 3
C) 8 5
D) 10 3
E) 8 7
