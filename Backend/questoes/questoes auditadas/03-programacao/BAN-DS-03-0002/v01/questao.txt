ENUNCIADO
Considere o programa Java 21 abaixo:

public class Exemplo {
    static class Base {
        String nome() { return "base"; }
    }
    static class Derivada extends Base {
        @Override String nome() { return "derivada"; }
    }
    static String identificar(Base item) { return "base"; }
    static String identificar(Derivada item) { return "derivada"; }
    public static void main(String[] args) {
        Base item = new Derivada();
        System.out.print(item.nome() + "/" + identificar(item));
    }
}

O texto exibido ao executar o método main é

A) base/base
B) derivada/derivada
C) base/derivada
D) Não há saída, pois a chamada identificar(item) é ambígua.
E) derivada/base
