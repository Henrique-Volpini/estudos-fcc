ENUNCIADO
Considere o programa em C11, sem entrada externa:

#include <stdio.h>

int main(void) {
    int a = 0, b = 2, c = 4;
    int r = a && ++b || b > 1 && ++c;
    printf("%d %d %d", b, c, r);
    return 0;
}

A sequência exibida por printf é

A) 3 5 1
B) 2 4 0
C) 2 5 5
D) 3 4 1
E) 2 5 1
