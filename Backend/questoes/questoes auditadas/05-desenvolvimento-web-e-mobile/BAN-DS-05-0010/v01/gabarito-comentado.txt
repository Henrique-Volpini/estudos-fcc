ID: BAN-DS-05-0010
Versão: v01
Gabarito proposto: B
O que o comando pede: Determinar o conteúdo da string produzida por JSON.stringify.

RESOLUÇÃO
A propriedade apelido tem valor undefined e é excluída da serialização do objeto. A propriedade ativo permanece com false. No array contatos, o primeiro elemento undefined é representado por null, o segundo já é null e o terceiro continua sendo a string vazia. Sem o parâmetro space, não são acrescentados espaços de formatação. O resultado é {"ativo":false,"contatos":[null,null,""]}.

ANÁLISE INDIVIDUAL DAS ALTERNATIVAS
A) Não atende: uma propriedade de objeto com valor undefined é omitida, e não convertida em uma propriedade com valor null.
B) Atende: apelido é omitido, false é mantido, e o elemento undefined do array é representado por null sem remover a posição.
C) Não atende: o elemento undefined do array não é eliminado; sua posição é serializada como null, mantendo três elementos.
D) Não atende: undefined não é convertido no texto entre aspas undefined, nem em objeto nem em array.
E) Não atende: o valor booleano false possui representação JSON e não provoca a omissão da propriedade ativo.
