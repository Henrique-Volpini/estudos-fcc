Versão: v01
Gabarito proposto: C
O que o comando pede: Determinar o resultado ou exceção de três chamadas independentes à função.

RESOLUÇÃO
INTO STRICT exige que o comando produza exatamente uma linha. Para Z não há correspondências: é levantada NO_DATA_FOUND antes do RETURN. Para Y existe uma linha com valor nulo; sua cardinalidade satisfaz STRICT e v_valor recebe NULL, que é retornado. Para X há duas correspondências; valores iguais não reduzem a quantidade de linhas e a função não usa DISTINCT. Assim, é levantada TOO_MANY_ROWS. As chamadas foram declaradas independentes para que a falha de uma transação não impeça observar as demais.

ANÁLISE INDIVIDUAL DAS ALTERNATIVAS
A) Não atende. Esse comportamento corresponde ao SELECT INTO sem STRICT: ausência de linhas atribui NULL, e apenas a primeira linha entre várias é usada. A função apresentada exige exatamente uma linha.
B) Não atende. NO_DATA_FOUND ocorre quando a consulta não retorna linhas. Para Y existe uma linha, cujo valor é NULL; STRICT verifica cardinalidade, sem proibir um valor nulo nessa variável.
C) Atende. Z não retorna linhas e gera NO_DATA_FOUND. Y retorna exatamente uma linha, permitindo retornar NULL. X retorna duas linhas e gera TOO_MANY_ROWS, mesmo que os valores sejam iguais.
D) Não atende. As duas linhas de X continuam sendo duas linhas. A consulta não usa DISTINCT nem agregação, e STRICT não escolhe simplesmente a primeira delas.
E) Não atende. Com STRICT, a consulta sem linhas para Z não atribui silenciosamente NULL: ela gera NO_DATA_FOUND. Os comportamentos indicados para Y e X estão coerentes, mas o primeiro não.
