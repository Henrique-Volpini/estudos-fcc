ID: BAN-DS-04-0010
Versão: v01
Gabarito proposto: D
O que o comando pede: Determinar os identificadores selecionados pela condição com IS NULL e comparação por igualdade a NULL.

RESOLUÇÃO
No Oracle 19c, a cadeia de caracteres de comprimento zero é tratada como NULL; assim, os registros 1 e 2 têm apelido nulo. A condição IS NULL é verdadeira nessas duas linhas. O teste apelido = NULL produz UNKNOWN, inclusive para valores nulos. Com OR, TRUE combinado com UNKNOWN continua TRUE, selecionando 1 e 2. Para os registros 3 e 4, IS NULL é FALSE e FALSE OR UNKNOWN resulta UNKNOWN; o WHERE não seleciona essas linhas. ORDER BY id organiza a saída como 1, 2.

ANÁLISE INDIVIDUAL DAS ALTERNATIVAS
A) Não atende. Além do NULL explícito do registro 1, a cadeia de comprimento zero inserida no registro 2 é tratada como NULL pelo Oracle 19c.
B) Não atende. O texto '0' tem um caractere e não é NULL. Para o registro 3, IS NULL é falso e a igualdade a NULL produz UNKNOWN; a linha não satisfaz o WHERE.
C) Não atende. Os registros 3 e 4 têm valores não nulos. Comparar seus valores com NULL não torna a condição verdadeira; produz UNKNOWN.
D) Atende. Os registros 1 e 2 têm apelido nulo no Oracle 19c. Neles, IS NULL é verdadeiro e o OR resulta verdadeiro. Nos demais, a condição não é verdadeira.
E) Não atende. A igualdade a NULL produz UNKNOWN, mas não anula um operando verdadeiro do OR. Nos registros 1 e 2, IS NULL basta para tornar a condição verdadeira.
